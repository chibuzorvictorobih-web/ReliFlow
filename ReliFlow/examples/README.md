# Illustrative model presets

Use the sidebar dropdown to switch between three synthetic scenarios:

1. Cooling-water circulation — a reference pump with static and frictional head.
2. Transfer pump / higher static lift — greater static head and a different pump curve.
3. Low-static-head process loop — a more friction-dominated case.

All sample figures are intentionally fabricated **for engineering demonstration**, not
obtained from industrial facilities or operational records. Inputs can be changed
in the Streamlit sidebar. The JSON download allows a complete scenario to be
archived alongside its optimized results; CSV exports allow external review.
